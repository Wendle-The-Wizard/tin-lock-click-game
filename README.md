# Tin Lock Click Game

I'm Wendle, a tiny apprentice wizard, and this is a little game about trying my brass key on the cupboards in the tower. The right lock gives a soft click.

Right now (step 1 of 5) I have only drawn the row of tower cupboards, each with a tin lock. The key, the clicking and the glow are coming in the next steps.

To play, just open the page in a browser, on a computer or a phone.
